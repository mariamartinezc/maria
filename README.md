### 🚀 Mi Proyecto Destacado: Portal de Educación Superior en Chile
Desarrollé una plataforma 100% Cloud para centralizar la oferta académica de la educación superior en Chile. El sistema automatiza la recolección de datos y los presenta de forma clara.

* **Frontend:** Desplegado en **Vercel**.
* **Backend y Base de Datos:** Construido sobre **Supabase** y **PostgreSQL**.
* **Automatización:** Web scraping programado mediante un **Cron job mensual** en **GitHub Actions**, el cual se ejecuta de manera 100% automatizada para extraer datos de los centros educacionales y mantener nuestra base de datos actualizada de forma periódica.
